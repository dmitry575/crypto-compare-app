# Материалы для карточки в магазине

Скриншоты для RuStore, 1920×1080 (16:9). Сняты на версии 2.1.0 (`versionCode` 5)
на боевом бэкенде, интерфейс русский.

| Файл | Экран | Тема |
|---|---|---|

| `02-portfolio-dark.png` | портфель: стоимость и прибыль | тёмная |
| `03-chart-light.png` | график пары с SMA и EMA | светлая |
| `04-chart-dark.png` | график пары с SMA и EMA | тёмная |
| `05-comparison-light.png` | сравнение бирж | светлая |
| `06-catalog-light.png` | каталог, фильтр «Растут» | светлая |
| `07-networks-light.png` | каталог, символы по сетям | светлая |
| `08-comparison-dark.png` | сравнение бирж | тёмная |
| `09-catalog-dark.png` | каталог, фильтр «Растут» | тёмная |
| `10-networks-dark.png` | каталог, символы по сетям | тёмная |

Порядок в карточке — по номеру: сначала то, что появилось в 2.1.0 (портфель и
индикаторы на графике), потом остальное, ради чего приложение ставят.

Текст «Что нового» для текущей версии — `store/whats-new-2.1.1.md`
(прошлые версии лежат рядом). Для 2.1.1 скриншоты не переснимались: экраны
те же, только в строках портфеля появилась подпись биржи («на binance»,
«по цене htx»).

Цены на снимках живые, поэтому при пересъёмке они не совпадут с этими — это не
ошибка. Пересобирать комплект имеет смысл, когда экран заметно меняется: снимок
экрана с устройства (`adb exec-out screencap -p`), поверх — панель, заголовок и
подпись в цветах темы (`core/ui/.../theme/Color.kt`). Строка состояния на снимках
чистая, потому что на время съёмки включён демо-режим SystemUI
(`adb shell am broadcast -a com.android.systemui.demo -e command enter`, часы
12:00, полная батарея; выключается командой `exit`).
