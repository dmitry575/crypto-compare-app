# Материалы для карточки в магазине

Скриншоты для RuStore, 1920×1080 (16:9). Сняты на версии 2.0.0 (`versionCode` 4)
на боевом бэкенде, интерфейс русский.

| Файл | Экран | Тема |
|---|---|---|
| `01-comparison-light.png` | сравнение бирж | светлая |
| `02-catalog-light.png` | каталог, фильтр «Растут» | светлая |
| `03-networks-light.png` | каталог, символы по сетям | светлая |
| `04-chart-light.png` | детали пары и график | светлая |
| `05-comparison-dark.png` | сравнение бирж | тёмная |
| `06-catalog-dark.png` | каталог, фильтр «Растут» | тёмная |
| `07-networks-dark.png` | каталог, символы по сетям | тёмная |
| `08-chart-dark.png` | детали пары и график | тёмная |

Порядок в карточке — по номеру: первым идёт сравнение бирж, ради него приложение и
ставят.

Цены на снимках живые, поэтому при пересъёмке они не совпадут с этими — это не
ошибка. Пересобирать комплект имеет смысл, когда экран заметно меняется: снимок
экрана с устройства (`adb exec-out screencap -p`), поверх — панель, заголовок и
подпись в цветах темы (`core/ui/.../theme/Color.kt`).
