# Что нового — 2.1.1

`versionCode` 6, `versionName` 2.1.1.

## Текст для карточки RuStore (русский)

```
Портфель: у позиции можно указать биржу, где куплена монета, — стоимость и
прибыль считаются по её цене, а не по лучшей среди всех бирж. В строке видно,
чья цена взята, а без сети остаётся последняя известная.

Портфель, как и каталог, предупреждает, когда цены перестали обновляться, и
даёт обновить их вручную.

Ещё: понятные ошибки с кнопкой «Повторить», пары везде в виде BTC/USDT,
быстрее первый запуск, удобнее с TalkBack.

Исправили: каталог больше не теряет пары при загрузке.
```

## English

```
Portfolio: a position can now name the exchange where the coin was bought —
its value and profit follow that exchange's price instead of the best one
across all exchanges. Each row shows whose price it is, and without a
network the last known price stays.

Like the catalog, the portfolio now tells you when prices stop updating and
lets you refresh them by hand.

Also: clear error messages with a Retry button, pairs shown as BTC/USDT
everywhere, a faster first launch, better TalkBack support.

Fixed: the catalog no longer loses pairs while it loads.
```

## Что вошло в релиз целиком

**Биржа покупки у позиции** (#83: #86, #90) — поле «Биржа покупки» в форме
позиции; позиция с биржей оценивается по её bid, без биржи — по лучшему bid, как
раньше. В строке видно источник цены («на binance», «по цене htx»). Последние
цены бирж хранятся в `portfolio_quotes`, поэтому без сети позиция не пустеет.

**Полоска «цены не обновляются» в портфеле** (#93) — та же, что в каталоге, с
«Обновить».

**Единая модель ошибок** (#46: #87, #88) — ошибки приходят типом, а не текстом
исключения; текст на языке интерфейса подбирает UI. Экран пары без сети
показывает причину и «Повторить» вместо «Нет данных по биржам»; на входе
подсвечивается ровно то поле, про которое ошибка, и гаснет, как только его
правят (#96). Непредвиденные сбои уходят в Crashlytics (#91).

**Каталог** — выкачка в стабильном порядке, пары больше не пропадают на время
загрузки (#84); фоновая перекачка раз в 20 минут дошла и до старых установок
(#89). Лучшие цены из сокета пишет в базу один писатель на приложение, а не
каждый экран (#94).

**Мелочи** (#85, #92, #96) — «BTC/USDT» на всех экранах; кнопка Google спрятана
там, где нет сервисов Google, и предлагает обновить устаревшие; тики не пишутся
в логи релизной сборки; ошибка экрана пары не всплывает повторно; поле биржи и
карточка итога читаются TalkBack'ом целиком.

**Техническое** — Room 12 (`providerId` у позиции, таблица `portfolio_quotes`),
политика кешей (`core/data/CACHE_POLICY.md`, #45), типизированная навигация
(#97), генератор baseline profile (#95; сам профиль лежит локально и попадает
только в сборку для RuStore).
