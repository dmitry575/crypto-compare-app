# Baseline profile

Модуль снимает baseline profile приложения. Это список классов и методов, которые
нужны на холодном старте и на главных путях: каталог с прокруткой, экран пары
с графиком, портфель. ART компилирует их заранее при установке, а не
интерпретирует первые запуски. `profileinstaller` в `app` ставит профиль,
даже если магазин этого не сделал.

Готовый профиль лежит в `app/src/release/generated/baselineProfiles/` и **в
репозиторий не идёт** — его закрывает правило `**/release` в `.gitignore`.
Это генерируемый файл на десятки тысяч строк, и нужен он только там, где
собирается релиз для RuStore, то есть локально: у RuStore нет API для
публикации из CI. Локальная сборка `release` подхватывает профиль сама,
если файл на месте; без файла она просто собирается без него. Сборка из CI
(APK в телеграм) профиля не получает, и это ни на что не влияет.

## Когда перегенерировать

Перед сборкой для RuStore, если файла нет (новая машина, чистый клон) или
после заметных изменений на пути генератора: новый экран на старте, другой
каталог, смена навигации. Устаревший профиль не ломает приложение, он просто
помогает меньше. Что профиль попал в сборку, видно по
`assets/dexopt/baseline.prof` внутри APK.

## Как

**Только на отдельном эмуляторе.** Прогон ставит релизную сборку с тем же
`applicationId` и после себя удаляет её. На рабочем эмуляторе это снесёт
приложение вместе со входом в аккаунт.

1. Остановить рабочие эмуляторы — подключено должно быть одно устройство.
2. Поднять чистый эмулятор с API 33+ (профиль снимается без root начиная с 33):

   ```bash
   emulator -avd BaselineProfile -wipe-data -no-snapshot -no-boot-anim -no-window
   ```

   AVD `BaselineProfile` — копия конфигурации рабочего, без его данных.
3. Проверить, что подключён именно он: `adb emu avd name`.
4. Снять профиль:

   ```bash
   ANDROID_SERIAL=emulator-5554 ./gradlew :app:generateReleaseBaselineProfile
   ```

Генератор идёт по английскому интерфейсу чистой установки: пропускает
онбординг, листает каталог, открывает пару и портфель. Каталог и график
приходят из сети, поэтому нужен доступ к бэкенду из `RELEASE_BASE_URL`.

Варианты `nonMinifiedRelease` и `benchmarkRelease` подписываются отладочным
ключом: ключ релиза есть только в CI, а в магазин эти сборки не идут.
